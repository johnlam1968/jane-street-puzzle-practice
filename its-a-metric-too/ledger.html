Assumption ledger

Paint the states you are assuming, mark the capitols you are assuming — including the hidden ones — and every published number is re-checked against the real travel costs. The capitol map shows where a capitol could be; this page shows what your assumptions cost you.

Coordinates — columns (X) are numbered across the top, rows (Y) down the left; a square is named rNcM, so r2c5 is column 5 of row 2. Top-left of a square — the area of the state it is in; a ✱ means that state has no capitol (its symmetries fix more than one square, or none), so it contributes no destination and every step inside it costs the whole area. Walls — the bold lines between squares are the state borders, and they carry the symmetry check: a dark line is a plain border, an amber line marks a state with no capitol (it goes nowhere), and a red line marks a painted region with no symmetry at all — that is not a state yet, so repaint it with a mirror or a rotation. Bottom-right — the cheapest distance from that square to a capitol we already know about, if every unknown square were as small as possible. It is a floor, not the answer: a hidden capitol can be nearer, which is exactly what a number below that floor demands. Bottom-left — the cost the current assumptions actually pin down: the cheapest route to a known or assumed capitol that uses only squares whose state size is known. Where no such route exists yet, nothing is shown there — the free squares would have to be sized first. Its colour compares that cost with the published number in the same square: black and bold when they agree, green when the calculated cost is higher, amber when it is lower. Top-right — the verdict, as a badge: ● confirmed (the assumptions pin the number exactly), ○ open (payable, but not pinned down yet), ▲ demand (an unrevealed capitol has to be nearer), ✕ contradicted (a known capitol is cheaper, so the number is wrong).
