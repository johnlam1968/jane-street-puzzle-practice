Legends

Every mark on the board, one paragraph each.

Play the harness Agent Onboarding Chinese version

Coordinates — columns (X) are numbered across the top, rows (Y) down the left; a square is named rNcM, so r2c5 is column 5 of row 2.

Top-left of a square — the area of the state it is in; a ✱ means that state has no capitol (its symmetries fix more than one square, or none), so it contributes no destination and every step inside it costs the whole area.

Walls — the bold lines between squares are the state borders, and they carry the symmetry check: a dark line is a plain border, an amber line marks a state with no capitol (it goes nowhere), and a red line marks a painted region with no symmetry at all — that is not a state yet, so repaint it with a mirror or a rotation.

Bottom-right — the cheapest distance from that square to a capitol we already know about, if every unknown square were as small as possible. It is a floor, not the answer: a hidden capitol can be nearer, which is exactly what a number below that floor demands.

Bottom-left — the cost the current assumptions actually pin down: the cheapest route to a known or assumed capitol that uses only squares whose state size is known. Where no such route exists yet, nothing is shown there — the free squares would have to be sized first. Its colour compares that cost with the published number in the same square: black and bold when they agree, green when the calculated cost is higher, amber when it is lower.

Top-right — the verdict, as a badge: ● confirmed (the assumptions pin the number exactly), ○ open (payable, but not pinned down yet), ▲ demand (an unrevealed capitol has to be nearer), ✕ contradicted (a known capitol is cheaper, so the number is wrong).

C at the bottom — a constraint you set on that square: green when it holds, red when it is broken, amber when it cannot be decided yet.

Dashed ring in the middle — the square could host a hidden capitol: rest the pointer on a number that needs one (hold it on a touch screen) and every square that could carry it is ringed.
